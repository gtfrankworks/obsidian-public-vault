# 🚀 快速开始

## 安装

### 一键安装（推荐）

```bash
curl -fsSL https://hermes-agent.sh | sh
```

使用 uv 安装，自动处理 Python 版本依赖。安装目录：`~/.hermes/hermes-agent/`

### 升级

```bash
hermes upgrade
# 或指定版本
hermes upgrade --version 2026.4.20
```

### 检查当前版本

```bash
hermes --version
```

---

## 初始化配置

```bash
hermes init
```

生成 `~/.hermes/config.yaml`，这是 Hermes 的核心配置文件。

---

## LLM 提供者配置

编辑 `~/.hermes/config.yaml`，设置 API Key：

```yaml
providers:
  deepseek:
    api_key: "sk-xxxxxxxxxxxxxxxx"
    # 默认模型
    default_model: deepseek-v4-flash
```

### 支持的提供者

开箱即用 25+ 提供者：

| 提供者 | 配置 key | 说明 |
|--------|---------|------|
| OpenAI | `openai` | GPT-4o / o1 / o3 系列 |
| Anthropic | `anthropic` | Claude 系列 (Sonnet/Opus) |
| DeepSeek | `deepseek` | DeepSeek V4 |
| Google | `google` | Gemini 系列 |
| Groq | `groq` | 极速推理 |
| OpenRouter | `openrouter` | 聚合多模型 |
| 自托管 | `ollama`/`vllm`/`sglang` | 本地部署 |

## CLI 常用命令

### 对话

```bash
hermes chat                    # TUI 交互模式（默认）
hermes chat -m "你的问题"      # 一次问答（非交互）
hermes chat --no-tui           # 纯文本（无 TUI）
hermes chat --model claude-sonnet-4  # 指定模型
```

### 会话管理

```bash
hermes sessions list           # 列出所有会话
hermes sessions browse         # 交互式浏览
hermes sessions export output.jsonl  # 导出
hermes sessions prune --older-than 30  # 清理30天前的
```

### 网关

```bash
hermes gateway run             # 启动网关
hermes gateway status          # 查看网关状态
hermes gateway stop            # 停止网关
```

### 系统

```bash
hermes status                  # 系统状态检查
hermes config show             # 显示当前配置
hermes config validate         # 验证配置
hermes doctor                  # 诊断问题
```

## 配置文件结构

`~/.hermes/config.yaml` 主要区块：

```yaml
hermes:           # Hermes 自身配置
providers:        # LLM 提供者
gateway:          # 消息网关
skills:           # 技能配置
memory:           # 记忆系统
tools:            # 工具配置
cron:             # 定时任务
plugins:          # 插件
logging:          # 日志
```

## 启动工作流（本地开发）

```bash
# 1. 启动聊天（单用户）
hermes chat

# 2. 启动网关（多平台接入）
hermes gateway run

# 3. 启动 API Server（供外部调用）
echo 'API_SERVER_ENABLED=true' >> ~/.hermes/.env
echo 'API_SERVER_KEY=my-local-key' >> ~/.hermes/.env
hermes gateway run  # 重启后生效
```
