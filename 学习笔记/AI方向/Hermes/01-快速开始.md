## 安装

### 一键安装（推荐）

```bash
curl -fsSL https://hermes-agent.sh | sh
```

这行命令走的是 uv 安装，自动处理 Python 版本——不用管 Python 是 3.10 还是 3.12，它自己搞定。装完以后东西全在 `~/.hermes/hermes-agent/`。

我第一次装的时候犯了个蠢：**忘了先装 uv**。结果脚本跑到一半卡住了。如果你也遇到这种情况，先跑一句：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

然后再装 Hermes，一路绿灯。

### 升级 & 版本管理

```bash
hermes upgrade                          # 升到最新
hermes upgrade --version 2026.4.20      # 升到指定版本
hermes --version                        # 当前版本
```

> **踩坑提醒**：升级前最好看一眼 `hermes status` 看看当前配置有没有标红的项目。我升级 2026.4.20 的时候，因为少看了配置里一个废弃字段，gateway 起不来了。折腾了十分钟才发现是旧配置和新版本不兼容。

## 初始化配置

```bash
hermes init
```

这条命令会在 `~/.hermes/config.yaml` 生成一个默认配置。这个文件是 Hermes 的心脏——后面改 API Key、配消息渠道、调工具权限，全在这里改。

**我的建议**：初始化完立刻做两件事：

1. `hermes config validate` — 验证一次，确保基础格式没错
2. `hermes doctor` — 全身体检，它会告诉你哪些依赖没装、哪些端口被占了

这两步花不了一分钟，但是能帮你省掉后面定位问题的时间 🤦

## LLM 提供者配置

打开 `~/.hermes/config.yaml`，找到 `providers` 字段，把 API Key 填进去：

```yaml
providers:
  deepseek:
    api_key: "sk-xxx...xxxx"
    default_model: deepseek-v4-flash
```

**说句实话** —— API Key 怎么填取决于你用谁家。我试过的几个：

| 提供者 | 配置 key | 说人话 |
|--------|---------|--------|
| OpenAI | `openai` | GPT 全家桶，贵但稳 |
| Anthropic | `anthropic` | Claude Sonnet 写代码是真舒服 |
| DeepSeek | `deepseek` | 性价比王——我现在主力用这个 |
| Google | `google` | Gemini 长上下文打不过就加入 |
| Groq | `groq` | 快是真快，但模型选择少 |
| OpenRouter | `openrouter` | 不想绑一家就搞个聚合 |
| Ollama/vLLM | `ollama`/`vllm` | 本地跑，不用怕泄漏代码 |

> **一个小发现**：支持 25+ 提供者没错，但你大概率只用 1-2 个。别被数字吓到，深挖一家就够了。我一开始各家都配了一遍，后来全删了，只留 DeepSeek 和 Claude。

## CLI 常用命令

### 对话

```bash
hermes chat                     # TUI 模式，我最常用的
hermes chat -m "你的问题"       # 问一句就跑
hermes chat --no-tui            # 纯文本，SSH 连服务器时用
hermes chat --model claude-sonnet-4  # 临时换模型
```

TUI 模式第一次启动时，底下那个输入框我找了三秒——其实就是最底下那条闪的光标。进去以后按 `/` 可以调 slash 命令，我手动打了一个月才知道这个快捷键。

### 会话管理

```bash
hermes sessions list            # 看所有历史
hermes sessions browse          # 交互式翻历史
hermes sessions export output.jsonl  # 导出来做分析
hermes sessions prune --older-than 30  # 清30天以前的
```

sesions 存在 SQLite 里（`~/.hermes/state.db`），删了这个文件就是删了所有对话。想安全清理用 `prune` 命令，别手滑直接 rm。

### 网关

```bash
hermes gateway run              # 启动网关
hermes gateway status           # 看看跑没跑
hermes gateway stop             # 关掉
```

Gateway 是最让我觉得「这玩意儿有点东西」的功能——配好以后，微信上发一条消息，AI 直接干活。这种感觉比打开网页跟 AI 聊天爽一个量级。

### 系统诊断

```bash
hermes status                   # 系统状态一览
hermes config show              # 当前配置
hermes config validate          # 校验配置
hermes doctor                   # 全身体检
```

> `hermes doctor` 推荐**刚装完就跑一次**。它查的东西包括：Python 环境、系统依赖、端口占用、配置完整性。我第一遍装完就是靠这个发现缺了 `ffmpeg`（网关的语音功能需要它）。

## 配置文件结构

`~/.hermes/config.yaml` 打开以后大概长这样——别慌，大部分字段有默认值：

```yaml
hermes:        # Hermes 自己的行为
providers:     # LLM 提供者
gateway:       # 消息网关
skills:        # 技能系统
memory:        # 记忆系统
tools:         # 工具配置
cron:          # 定时任务
plugins:       # 插件
logging:       # 日志
```

**翻译成人话**：这个配置文件就是 Hermes 的中枢控制台。大部分时候你只需要碰 `providers` 和 `gateway`。其他的要么有默认值，要么用 `hermes init` 的推荐配置就够了。

## 快速上手

```bash
# 最简工作流——三行搞定：
hermes chat                                # 1. 聊起来
hermes gateway run                         # 2. 开网关（接入微信/Telegram）
# 想暴露成 API 给其他程序调？
echo 'API_SERVER_ENABLED=true' >> ~/.hermes/.env
echo 'API_SERVER_KEY=my-local-key' >> ~/.hermes/.env
hermes gateway run                         # 3. 重启，API Server 就亮了
```
