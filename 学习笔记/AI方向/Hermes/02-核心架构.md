# 🏛️ 核心架构

## Agent Loop（代理循环）

Hermes 的核心是一个 **循环式 Agent**，不是简单的 Chat Completion。

### 基本流程

```
用户输入
    │
    ▼
┌─────────────────────────────────────┐
│ 1. Prompt Assembly（提示词组装）     │
│    ├─ System Prompt（系统提示词）    │
│    ├─ Persona（角色设定）            │
│    ├─ Memory（记忆注入）             │
│    ├─ Skills（技能注入）             │
│    ├─ Context Files（上下文文件）     │
│    └─ Tool Definitions（工具定义）   │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│ 2. LLM Call（调用大模型）            │
│    ├─ 发送组装好的 Prompt            │
│    ├─ 支持 tool_use / function_call   │
│    └─ 支持多轮工具调用的流式输出      │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│ 3. Response Handling（响应处理）     │
│    ├─ 文本响应 → 直接输出给用户      │
│    ├─ 工具调用 → 进入 Tool Exec      │
│    └─ 两者混合 → 并行处理            │
└─────────────┬───────────────────────┘
              │
         ┌────┴────┐
         ▼         ▼
      文本响应    工具调用
                   │
                   ▼
         ┌───────────────────┐
         │ Tool Execution    │
         │ ┌───────────────┐ │
         │ │ Tool1 →       │ │
         │ │ Tool2 → 并发  │ │
         │ │ ToolN →       │ │
         │ └───────┬───────┘ │
         │         │         │
         │ ▼       ▼         │
         │ 结果注入回 LLM     │
         └─────────┬─────────┘
                   │
                   ▼
         回到第2步（循环）
                │
                ▼
         直到 LLM 只返回文本
                │
                ▼
           输出给用户 🎉
```

### 循环终止条件

- LLM 只返回文本（无工具调用）
- 达到最大工具调用轮数（默认 50 轮）
- 超时（默认 600 秒）
- 用户中断

## Tools Runtime（工具运行时）

### 工具调用流程

```
LLM 返回 tool_calls
    │
    ▼
┌─────────────────────────────┐
│ Tool Registry（工具注册中心） │
│ ├─ Built-in Tools（内置）    │
│ ├─ Plugin Tools（插件）      │
│ └─ Custom Tools（自定义）     │
└──────────┬──────────────────┘
           │
           ▼
┌─────────────────────────────┐
│ Tool Execution              │
│ ├─ 权限检查（RABC）          │
│ ├─ 沙箱隔离（标准/严格）      │
│ ├─ 超时控制                  │
│ └─ 并发执行                   │
└──────────┬──────────────────┘
           │
           ▼
    结果注入回 LLM
```

### 工具类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **Built-in** | 内置于 Hermes | `terminal`, `read_file`, `web_search` |
| **Plugin** | 通过插件提供 | 社区贡献的工具包 |
| **MCP** | MCP 服务器发现 | native-mcp 客户端自动发现 |

### 关键配置

```yaml
tools:
  sandbox: strict          # 沙箱模式：off / standard / strict
  timeout: 60              # 工具默认超时（秒）
  max_tool_calls: 50       # 单次 Agent 循环最大工具调用数
```

### 沙箱级别

| 级别 | 限制 |
|------|------|
| `off` | 无限制（默认） |
| `standard` | 阻断高危命令（rm -rf、dd 等） |
| `strict` | 只允许白名单命令，拦截所有网络 |

## Prompt Assembly（提示词组装）

每次 LLM 调用前，Hermes 会动态组装 System Prompt：

```
系统提示词
├─ Persona（角色设定）── 从 ~/.hermes/config.yaml 的 persona 读取
├─ Memory（记忆）─────── 注入 user 和 memory 两条记忆
├─ Skills（技能）─────── 匹配的技能内容
├─ Context（上下文文件）── 项目根目录的 AGENTS.md / CLAUDE.md 等
├─ Tools（工具定义）──── 当前启用的工具集
└─ Instructions（指令）── 系统行为指令
```

### 相关配置

```yaml
hermes:
  persona: |
    你是一个智能助手...
  memory:
    enabled: true
    long_term: true
  tools:
    auto_discover: true     # 自动发现项目上下文文件
```

## Gateway（网关）

Gateway 是 Hermes 的 **多平台消息入口**，负责：

```
Telegram ───┐
Discord  ───┤
Slack    ───┤
微信      ───┤
飞书      ───┤
...20+ 平台 ─┤
             │
             ▼
    ┌──────────────┐
    │   Gateway    │
    │  ┌─────────┐ │
    │  │ Router  │ │
    │  └────┬────┘ │
    │       │      │
    │  ┌────▼────┐ │
    │  │ Session  │ │
    │  │ Manager  │ │
    │  └────┬────┘ │
    │       │      │
    │  ┌────▼────┐ │
    │  │  Auth   │ │
    │  └─────────┘ │
    └──────┬───────┘
           │
           ▼
    ┌──────────────┐
    │  Agent Loop  │
    └──────────────┘
```

### Gateway 配置

```yaml
gateway:
  # 消息平台配置
  telegram:
    enabled: true
    bot_token: "xxx"
  discord:
    enabled: true
    bot_token: "xxx"

  # 控制界面
  control_ui:
    enabled: true
    port: 8642

  # 安全配置
  rate_limit:
    enabled: true
    max_messages_per_minute: 30
```
