# 📖 参考手册

## CLI 命令速查

### 核心命令

```bash
hermes chat           # 启动交互对话（默认 TUI）
hermes chat -m "..."  # 单次问答
hermes chat --no-tui  # 纯文本模式
```

### 配置

```bash
hermes init                     # 初始化配置
hermes config show              # 显示配置
hermes config validate          # 验证配置
hermes config edit              # 编辑配置
hermes doctor                   # 诊断
```

### 会话

```bash
hermes sessions list            # 列会话
hermes sessions browse          # 浏览会话
hermes sessions show <id>       # 查看会话详情
hermes sessions export <file>   # 导出
hermes sessions prune           # 清理旧会话
hermes sessions delete <id>     # 删除
```

### 网关

```bash
hermes gateway run              # 启动
hermes gateway status           # 状态
hermes gateway stop             # 停止
hermes gateway restart          # 重启
```

### 技能

```bash
hermes skills list              # 列技能
hermes skills view <name>       # 查看
hermes skills create <name>     # 创建
hermes skills edit <name>       # 编辑
hermes skills delete <name>     # 删除
```

### 定时任务

```bash
hermes cron list                # 列任务
hermes cron run <id>            # 手动执行
hermes cron pause <id>          # 暂停
hermes cron resume <id>         # 恢复
hermes cron delete <id>         # 删除
```

### 检查点

```bash
hermes checkpoint save <name>   # 保存
hermes checkpoint list          # 列表
hermes checkpoint load <name>   # 加载
hermes checkpoint delete <name> # 删除
```

### 系统

```bash
hermes status                   # 系统状态
hermes version                  # 版本
hermes upgrade                  # 升级
hermes plugin list              # 插件列表
hermes plugin install <url>     # 安装插件
```

|------|------|
| `/help` | 显示帮助 |
| `/reset` | 重置当前会话 |

| `/retry` | 重试上次回复 |
| `/save` | 保存检查点 |
| `/load` | 加载检查点 |

| `/provider` | 切换提供者 |

| `/clear` | 清屏 |
| `/bye` | 退出 |

| `/summary` | 生成当前会话摘要 |

## 环境变量参考

所有环境变量通过 `~/.hermes/.env` 设置。

### 核心

| 变量 | 说明 |
|------|------|
| `HERMES_CONFIG` | 配置路径，默认 `~/.hermes/config.yaml` |
| `HERMES_HOME` | 数据目录，默认 `~/.hermes` |
| `HERMES_LOG_LEVEL` | 日志级别：debug/info/warn/error |

### API Server

| 变量 | 说明 |
|------|------|
| `API_SERVER_ENABLED` | 是否启用 API Server |
| `API_SERVER_KEY` | API Server 的认证密钥 |
| `GATEWAY_API_KEY` | 同上（兼容） |
