# 🚀 高级特性

## 子代理（Subagent / Delegation）

将任务委派给独立子 Agent，并发执行。

```yaml
delegation:
  max_concurrent_children: 3    # 默认3个并发
  max_spawn_depth: 1            # 嵌套深度（1=只能叶子，2=可再委派）
  orchestrator_enabled: false   # 是否允许编排者模式
```

### 使用方式

```python
# 单任务
delegate_task(
    goal="分析代码库结构",
    context="项目在 /path/to/project",
    toolsets=["terminal", "file"]
)

# 并行多任务
delegate_task(tasks=[
    {"goal": "检查后端 API", "toolsets": ["terminal"]},
    {"goal": "检查前端代码", "toolsets": ["terminal", "file"]},
])
```

### 角色类型

| 角色 | 能力 |
|------|------|
| `leaf`（叶子） | 可调用工具，不可再委派 |
| `orchestrator`（编排者） | 可再委派子任务 |

### 架构特点

- **同进程、多线程**：不是独立进程，无网络调用
- **隔离上下文**：每个子 Agent 独立会话
- **心跳保护**：5 秒心跳防止长任务超时
- **中断传播**：父被中断 → 子自动停止
- **进度回调**：子任务进度实时显示在 TUI

### ACP 模式（独立进程）

```python
delegate_task(
    goal="写一个 React 组件",
    acp_command="claude",        # 启动 Claude Code 子进程
    acp_args=["--acp", "--stdio"]
)
```

支持：Claude Code、OpenCode、Codex 等 ACP 兼容子进程。

## 定时任务（Cron）

内置调度器，无需外部 cron。

```yaml
cron:
  enabled: true
  jobs:
    # ── 定期任务 ──
    morning_brief:
      schedule: "0 8 * * *"     # 每天早上8点
      prompt: "生成今日简报并发送到 Telegram"
      enabled: true
    
    # ── 相对间隔 ──
    health_check:
      schedule: "30m"           # 每30分钟
      prompt: "检查各服务健康状态"
      script: ~/.hermes/scripts/health-check.py  # 前置脚本
    
    # ── 一次性 ──
    one_time_task:
      schedule: "2026-05-01T10:00:00"
      prompt: "执行一次性备份"
      repeat: 1
```

### 高级配置

```yaml
    # 链式任务
    data_collector:
      schedule: "0 */2 * * *"   # 每2小时
      prompt: "收集数据"
    
    data_processor:
      schedule: "30 */2 * * *"  # 晚半小时
      prompt: "处理数据"
      context_from: ["data_collector"]  # 等待上个任务结果

    # 技能驱动
    report:
      schedule: "0 9 * * 1"     # 每周一9点
      skills: ["weekly-report"]  # 先加载技能
      prompt: "执行周报生成"
```

### Cron 配置

```yaml
cron:
  workdir: /path/to/project  # 可选项目工作目录
  model:
    provider: deepseek       # 可选固定模型
    model: deepseek-v4-flash
  
  # 调度格式
  # "30m" / "every 2h"           → 相对时间
  # "0 8 * * *"                  → cron 表达式
  # "2026-05-01T10:00:00"       → ISO 时间戳
```

### 管理命令

```bash
hermes cron list       # 查看所有任务
hermes cron run <id>   # 手动执行
hermes cron pause <id> # 暂停
hermes cron resume     # 恢复
```

## Browser 自动化

内置无头浏览器，用于网页交互。

```yaml
tools:
  browser:
    headless: true
    timeout: 30000         # 毫秒
    viewport:
      width: 1280
      height: 720
```

### 可用工具

| 工具 | 功能 |
|------|------|
| `browser_navigate` | 导航到 URL |
| `browser_snapshot` | 获取页面快照（可访问性树） |
| `browser_click` | 点击元素 |
| `browser_type` | 输入文本 |
| `browser_scroll` | 滚动页面 |
| `browser_press` | 按键操作 |
| `browser_vision` | 截图 + 视觉分析 |
| `browser_get_images` | 列出页面图片 |
| `browser_console` | 获取控制台输出 / 执行 JS |
| `browser_back` | 返回上一页 |

### 典型用途

- 自动化表单填写
- 网页数据抓取
- CAPTCHA 识别（browser_vision）
- 页面状态检查
- E2E 测试

## Code Execution（代码执行）

Agent 内运行 Python 代码，可调用 Hermes 工具。

```yaml
tools:
  code_execution:
    enabled: true
    timeout: 300             # 5分钟
    docker:
      enabled: false
      image: "python:3.11"
```

### 可用的 Hermes 工具（代码内）

```python
from hermes_tools import read_file, write_file, search_files, patch, terminal, retry, json_parse, shell_quote

# 文件操作
result = read_file("path/to/file")
write_file("path/to/output", "content")

# 搜索
matches = search_files(pattern="TODO", path=".", file_glob="*.py")

# 编辑
patch(path="file.py", old_string="old", new_string="new")

# 终端
output = terminal("ls -la")

# 工具函数
data = json_parse(raw_text)          # 容错 JSON 解析
quoted = shell_quote(user_input)     # shell 安全转义
result = retry(fn, max_attempts=3)   # 重试
```

### 适用场景

| 场景 | 说明 |
|------|------|
| 3+ 工具调用 | 批量处理时减少上下文膨胀 |
| 条件分支 | if/else 逻辑处理 |
| 循环 | 遍历 N 个文件/页面 |
| 数据处理 | JSON/CSV 变换过滤 |
| 过滤器 | 工具输出太大时，代码内过滤 |

## Hooks（钩子系统）

三层钩子，在 Agent 循环的不同阶段插入自定义逻辑。

### 层级

```yaml
hooks:
  # 1️⃣ 前置钩子（Pre-hooks）
  pre_tool:
    - name: "log-tool"
      command: "echo 'Tool: $TOOL_NAME' >> /tmp/tool.log"
  
  # 2️⃣ 后置钩子（Post-hooks）
  post_tool:
    - name: "check-output"
      command: "validate_output.py $TOOL_RESULT"
  
  # 3️⃣ 失败钩子（On Error）
  on_error:
    - name: "notify-admin"
      command: "curl -X POST https://alert.example.com/error"
```

### 内置变量

| 变量 | 含义 |
|------|------|
| `$TOOL_NAME` | 工具名 |
| `$TOOL_INPUT` | 工具输入（JSON） |
| `$TOOL_RESULT` | 工具结果（JSON） |
| `$TOOL_ERROR` | 错误信息 |
| `$SESSION_ID` | 当前会话 ID |

## Checkpoints（检查点）

保存/恢复 Agent 状态，适合长任务。

```bash
# 手动检查点
hermes checkpoint save "before-refactor"

# 列出检查点
hermes checkpoint list

# 恢复
hermes checkpoint load "before-refactor"

# 自动检查点
hermes chat --auto-checkpoint  # 每轮自动保存
```

### 配置

```yaml
hermes:
  checkpoint:
    enabled: true
    auto: true            # 每轮自动保存
    dir: ~/.hermes/checkpoints/
    max_count: 10         # 最大保留数
    compression: true     # 压缩存储
```

## 上下文压缩（Context Compression）

防止长对话超出上下文窗口。

```yaml
hermes:
  session:
    compression:
      enabled: true
      strategy: summary    # summary / truncate / smart
      trigger_at: 80000    # 超过 80K tokens 触发
      preserve_first: 10   # 保留前 N 轮对话原文
```

### 策略

| 策略 | 行为 |
|------|------|
| `summary` | 将早期对话压缩为摘要 |
| `truncate` | 丢弃最早的部分 |
| `smart` | 分析重要性，只压缩不重要部分 |
