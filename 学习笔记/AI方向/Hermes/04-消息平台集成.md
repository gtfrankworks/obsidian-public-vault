# 📱 消息平台集成

Hermes 支持 **20+ 消息平台**，通过 Gateway 统一接入。

> [!tip] 我的接入建议
> 如果你是第一次接，**从 Telegram 或 Discord 开始**——社区最活跃、出问题好查。折腾通了再接其他的。
> 
> 每个平台的接入流程大同小异：创建 Bot → 拿凭证 → 写配置 → 启动 Gateway。

---

## 通用架构

```
各平台消息 → Gateway Adapter → 统一消息格式 → Agent Loop → 回写
```

每个平台需要：
1. 在对应平台创建 Bot/应用
2. 获取凭证（Token/Secret/AppID）
3. 在 `config.yaml` 配置对应的字段

---

## Telegram

上手最快，BotFather 两分钟搞定。

```yaml
gateway:
  telegram:
    enabled: true
    bot_token: "123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11"
```

| 特性 | 支持 |
|------|------|
| 私聊 | ✅ |
| 群组 | ✅ |
| 频道 | ✅ |
| 图片 | ✅ |
| 文件 | ✅ |
| 内联模式 | ✅ |

> [!tip] 创建 Telegram Bot
> 找 @BotFather → `/newbot` → 输名字 → 拿到 token 填进去，完事。不用配 Webhook，Gateway 自动用 Long Polling 接消息。

## Slack

两种模式可选：

- **Socket Mode**（推荐）— 无需公网，适合本地部署
- **HTTP Events API** — 需要公网端点，适合云上部署

```yaml
gateway:
  slack:
    enabled: true
    bot_token: "xoxb-..."
    signing_secret: "xxx"
    app_token: "xapp-..."      # Socket Mode 需要
```

| 特性 | 支持 |
|------|------|
| DM | ✅ |
| 频道 | ✅ |
| 提及 | ✅ |
| 斜杠命令 | ✅ |

> [!tip] 选 Socket Mode 省事
> 除非你的 Hermes 已经跑在公网服务器上，否则 Socket Mode 不用配防火墙和域名。

## 微信（WeChat）

使用 **微信公众平台** 的开发者模式，不是个人微信号。需要有一个已认证的公众号。

```yaml
gateway:
  wechat:
    enabled: true
    app_id: "wx..."
    app_secret: "xxx"
    token: "xxx"             # 验证用
    encoding_aes_key: "xxx"  # 加密模式需要
```

| 模式 | 说明 |
|------|------|
| 明文模式 | 开发调试用，不加密 |
| 兼容模式 | 明文 + 加密 |
| 安全模式 | 全加密（推荐生产） |

> [!warning] 微信需要公网
> 微信公众号要求配置公网 IP 或域名的 Webhook 回调地址。本地跑 Hermes 的话需要内网穿透（ngrok 之类的）。

## WhatsApp

需要 Meta Business 平台注册，配置 Webhook。

```yaml

    enabled: true
```

> 需要 Meta Business 账号 + 企业认证，对个人用户不太友好。个人玩的话还是 Telegram 或 Discord 省心。

## Email (IMAP/SMTP)

```yaml
gateway:
  email:
    enabled: true
    imap_server: "imap.gmail.com"
    imap_port: 993
    smtp_server: "smtp.gmail.com"
    smtp_port: 587
    username: "you@gmail.com"
    password: "xxx"          # 应用专用密码
    check_interval: 60       # 秒
```

> [!tip] Gmail 要用应用专用密码
> 不要用你的 Gmail 登录密码。去 Google 账号设置里生成一个「应用专用密码」，填到这里。

支持：收发邮件、附件处理。每次轮询检查新邮件，回复即发邮件回复。

## Webhooks

HTTP Webhook 收发，适合自定义集成。

```yaml
gateway:
  webhooks:
    enabled: true
    # 接收 Webhook
    receive:
      path: /webhook
      secret: "xxx"
    # 发送 Webhook
    send:
      default_url: "https://hooks.example.com/..."
```

## 多平台统一配置

每个平台可以单独覆盖全局设置：

```yaml
gateway:
  # 全局设置
  rate_limit:
    enabled: true
    max_messages_per_minute: 30
  
  session:
    timeout: 1800
    max_concurrent: 50
  
  # 平台专用覆盖
  discord:
    rate_limit:
      max_messages_per_minute: 60  # Discord 群人多，放开一点
```

> [!tip] 平台覆盖只在对应平台生效
> Telegram 依然走全局的 30 条/分钟，只有 Discord 用 60 条/分钟。每个平台的配置是独立的。
