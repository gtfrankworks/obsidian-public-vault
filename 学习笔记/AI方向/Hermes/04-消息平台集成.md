# 📱 消息平台集成

Hermes 支持 **20+ 消息平台**，通过 Gateway 统一接入。

---

## 通用架构

```
各平台消息 → Gateway Adapter → 统一消息格式 → Agent Loop → 回写
```

每个平台需要：
1. 在对应平台创建 Bot/应用
2. 获取凭证（Token/Secret/AppID）
3. 在 config.yaml 配置

---

## Slack

```yaml

  slack:
    enabled: true
    bot_token: "xoxb-..."
    signing_secret: "xxx"
    app_token: "xapp-..."      # Socket Mode 需要
```

|------|------|

## 微信（WeChat）

```yaml
gateway:
  wechat:
    enabled: true
    app_id: "wx..."
    app_secret: "xxx"
    token: "xxx"             # 验证用
    encoding_aes_key: "xxx"  # 加密模式需要
```

| 模式 | 说明 |
|------|------|
| 明文模式 | 开发调试用，不加密 |
| 兼容模式 | 明文 + 加密 |
| 安全模式 | 全加密（推荐生产） |

使用 **微信公众平台** 的开发者模式，非个人微信号。

## Email (IMAP/SMTP)

```yaml
gateway:
  email:
    enabled: true
    imap_server: "imap.gmail.com"
    imap_port: 993
    smtp_server: "smtp.gmail.com"
    smtp_port: 587
    username: "you@gmail.com"
    password: "xxx"          # 应用专用密码
    check_interval: 60       # 秒
```

支持：收发邮件、附件处理。每次轮询检查新邮件，回复即发邮件回复。

## 多平台统一配置

```yaml
gateway:
  # 全局设置
  rate_limit:
    enabled: true
    max_messages_per_minute: 30
  
  session:
    timeout: 1800
    max_concurrent: 50
  
  # 平台专用覆盖
  discord:
    rate_limit:
      max_messages_per_minute: 60  # Discord 可放宽
```
