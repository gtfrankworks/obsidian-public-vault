# ⚙️ 配置详解

核心配置文件 `~/.hermes/config.yaml`，YAML 格式。

---

## 顶层结构

```yaml
hermes:           # Hermes 自身行为配置
providers:        # LLM 提供者
gateway:          # 消息网关
skills:           # 技能系统
memory:           # 记忆系统
tools:            # 工具系统
cron:             # 定时任务
plugins:          # 插件
logging:          # 日志
```

---

## hermes（核心配置）

```yaml
hermes:
  persona: |
    你是 Friday，一个智能助手...
  
  # 默认模型
  default_model: deepseek-v4-flash
  
  # 默认提供者
  default_provider: deepseek
  
  # 会话
  session:
    max_turns: 200              # 单会话最大轮次
    auto_title: true            # 自动生成会话标题
    context_window: 128000      # 上下文窗口
    compression:
      enabled: true             # 上下文压缩
      strategy: summary         # summary / truncate / smart
      trigger_at: 80000         # 超过多少 token 触发压缩

  # 系统提示词目录
  system_prompt_dir: ~/.hermes/prompts/
```

---

## providers（提供者）

```yaml
providers:
  deepseek:
    api_key: "sk-xxxx"
    base_url: "https://api.deepseek.com/v1"
    default_model: deepseek-v4-flash
    max_retries: 3
    timeout: 60

  openai:
    api_key: "sk-xxxx"
    default_model: gpt-4o

  # 自托管
  ollama:
    base_url: "http://localhost:11434"
    api_key: "not-needed"
    default_model: llama3
```

### 提供者路由

```yaml
route:
  enabled: true
  rules:
    # 按模型能力路由
    - tool: vision           # 视觉任务 → 指定模型
      provider: openai
      model: gpt-4o
    - tool: code_execution   # 代码任务
      provider: anthropic
      model: claude-sonnet-4
```

### Credential Pools（多 Key 负载均衡）

```yaml
providers:
  openai:
    credential_pool:
      - api_key: "sk-key1"
        weight: 3             # 权重，默认1
        max_concurrent: 10    # 最大并发
      - api_key: "sk-key2"
        weight: 1
        max_concurrent: 5
```

## gateway（消息网关）

```yaml
gateway:
  # ── 消息平台 ──
  telegram:
    enabled: true
    bot_token: "xxx"
  
  discord:
    enabled: true
    bot_token: "xxx"
    guild_id: "xxx"
  
  slack:
    enabled: true
    bot_token: "xxx"
    signing_secret: "xxx"
  
  wechat:
    enabled: true
    app_id: "xxx"
    app_secret: "xxx"
  
  feishu:
    enabled: true
    app_id: "xxx"
    app_secret: "xxx"
  
  # ── 监控与控制 ──
  control_ui:
    enabled: true
    port: 8642
    allow_insecure_auth: true   # ⚠️ 本地调试方便，生产关闭

  # ── 速率限制 ──
  rate_limit:
    enabled: true
    max_messages_per_minute: 30
    burst: 10
  
  # ── 会话管理 ──
  session:
    timeout: 1800             # 会话超时（秒）
    max_concurrent: 50
  
  # ── 节点配置 ──
  nodes:
    deny_commands: []
    allowed_roles: ["user", "admin"]
```

## tools（工具系统）

```yaml
tools:
  # 沙箱安全
  sandbox: strict          # off / standard / strict
  
  # 超时
  timeout: 60
  
  # 最大工具调用轮数
  max_tool_calls: 50
  
  # 自动包含的工具包
  toolset: default         # default / minimal / full / none
  
  # 自定义工具
  custom_tools_dir: ~/.hermes/tools/
  
  browser:
    headless: true
    timeout: 30000
  
  code_execution:
    enabled: true
    timeout: 300
    docker:
      enabled: false       # 可选 Docker 沙箱
      image: "python:3.11"
```

---

## skills（技能系统）

```yaml
skills:
  enabled: true
  auto_load: true         # 启动时自动加载匹配技能
  
  # 技能目录
  directories:
    - ~/.hermes/skills/
    - ~/.hermes/plugins/*/skills/
  
  # 匹配规则
  matching:
    strategy: semantic      # keyword / semantic / hybrid
    threshold: 0.7
```

---

## memory（记忆系统）

```yaml
memory:
  enabled: true
  long_term: true
  
  stores:
    user:                   # 用户画像
      provider: file
      path: ~/.hermes/memory/user.md
    memory:                 # 通用笔记
      provider: file
      path: ~/.hermes/memory/memory.md
  
  # 记忆管理
  max_memory_items: 100
  dedup: true               # 去重
  auto_consolidate: true    # 自动合并
  consolidation_threshold: 20   # 超过多少条自动合并
```

---

## cron（定时任务）

```yaml
cron:
  enabled: true
  
  jobs:
    morning_report:
      schedule: "0 8 * * *"        # 每天早上8点
      prompt: "生成今日简报"
      enabled: true
```

---

## plugins（插件）

```yaml
plugins:
  enabled: true
  directory: ~/.hermes/plugins/
  auto_install: true
  
  # 插件列表
  sources:
    - type: github
      url: "https://github.com/user/hermes-plugin"
```

---

## logging（日志）

```yaml
logging:
  level: info              # debug / info / warn / error
  file: ~/.hermes/hermes.log
  max_size: 10MB
  backup_count: 5
  format: json             # text / json
```

---

## .env 文件

`~/.hermes/.env` 存放敏感信息（API Key 等），优先级高于 config.yaml：

```bash
# API Server
API_SERVER_ENABLED=true
API_SERVER_KEY=my-local-key

# 提供者 API Key（覆盖 config.yaml）
OPENAI_API_KEY=sk-xxxx
ANTHROPIC_API_KEY=sk-xxxx

# 代理
HTTP_PROXY=http://127.0.0.1:7890
HTTPS_PROXY=http://127.0.0.1:7890
```

## 配置验证

```bash
hermes config validate          # 检查语法
hermes config show              # 显示完整配置（隐藏 API Key）
hermes doctor                   # 全面诊断
```
