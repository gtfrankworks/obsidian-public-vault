# 🔌 集成与部署

把 Hermes 跑在 Docker 里、暴露成 API、接 Open WebUI、配 IDE 集成……这篇讲的是「跑起来之后」的事。

> [!tip] 先确认需求再动手
> - 只想本地 CLI 用 → 不需要这篇
> - 想从 Telegram/Discord 跟它聊 → 看 [[04-消息平台集成]]
> - 想让别人也能用 → 从这里开始

---

## Docker 部署

### 官方 Docker 镜像

```bash
# 拉取
docker pull ghcr.io/nousresearch/hermes-agent:latest

# 运行
docker run -d \
  --name hermes \
  -v ~/.hermes:/home/hermes/.hermes \
  -p 8642:8642 \
  ghcr.io/nousresearch/hermes-agent:latest
```

### docker-compose.yml

```yaml
version: '3.8'
services:
  hermes:
    image: ghcr.io/nousresearch/hermes-agent:latest
    container_name: hermes
    volumes:
      - ~/.hermes:/home/hermes/.hermes
    ports:
      - "8642:8642"
    restart: unless-stopped
    environment:
      - HERMES_LOG_LEVEL=info
```

> [!tip] 挂载 `~/.hermes`
> 配置文件、`.env`、记忆文件、技能——都在这个目录里。不挂载的话，容器重启就什么都没了。

## API Server（OpenAI 兼容）

把 Hermes 变成 OpenAI 兼容的 API 服务——这样 Open WebUI、Cursor、Continue 这些工具就能把它当「本地 OpenAI」来调。

### 启用

```bash
echo 'API_SERVER_ENABLED=true' >> ~/.hermes/.env
echo 'API_SERVER_KEY=my-local-key' >> ~/.hermes/.env
hermes gateway run
```

### 验证

```bash
# 健康检查
curl http://localhost:8642/v1/health
# → {"status": "ok"}

# Chat Completion（兼容 OpenAI 格式）
curl http://localhost:8642/v1/chat/completions \
  -H "Authorization: Bearer *** \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [{"role": "user", "content": "你好"}]
  }'
```

### 支持端点

| 端点 | 功能 |
|------|------|
| `GET /v1/health` | 健康检查 |
| `POST /v1/chat/completions` | Chat Completion（兼容） |
| `GET /v1/models` | 模型列表（兼容） |

> [!tip] API Key 不验证
> API Server 的 key 只是在 `.env` 里设一个标识，客户端发什么 key 都能用。如果想真正验证，参考[[06-安全与隐私]]关掉 `allowInsecureAuth`。

### 与 Open WebUI 集成

1. 启动 API Server（见上）
2. Open WebUI → 管理员设置 → 外部连接
3. 添加：
   - URL: `http://host.docker.internal:8642/v1`
   - API Key: `my-local-key`

> [!warning] `host.docker.internal` 需要显式添加
> Open WebUI 容器需要这个参数才能访问宿主机上跑着的 API Server：
> ```bash
> docker run --add-host=host.docker.internal:host-gateway ...
> ```
> docker-compose 里加 `extra_hosts:` 也能实现。

## ACP（Agent Communication Protocol）

让 Hermes 跟其他 ACP 兼容的 Agent 互相调用。

### 作为客户端——调用别的 Agent

```python
delegate_task(
    goal="写一个 Python 脚本",
    acp_command="claude",        # 启动 Claude Code
    acp_args=["--acp", "--stdio"]
)
```

支持：Claude Code、OpenCode、Codex（OpenAI）。

### 作为服务端——被别的 Agent 调

```bash
# 其他 ACP 客户端连接 Hermes
other-agent --acp-connect hermes://localhost:8642
```

> [!tip] ACP 场景
> 当你需要 Claude Code 的代码重构能力，但又不想切出 Hermes 的对话时——用 ACP 把它当子 Agent 调。具体见 [[05-高级特性#ACP 模式]]。

## 外部 IDE 集成

### Cursor

```yaml
设置 → 模型 → 添加自定义模型
- 名称: hermes
- 基础 URL: http://localhost:8642/v1
- API 密钥: my-local-key
```

### VS Code（Continue 插件）

```json
{
  "models": [
    {
      "title": "Hermes",
      "provider": "openai",
      "model": "deepseek-v4-flash",
      "apiBase": "http://localhost:8642/v1",
      "apiKey": "***"
    }
  ]
}
```

> [!tip] 这样 IDE 里就能用 Hermes 的模型了
> 配合[[09-提供者与模型#模型路由]]，你在 IDE 里写代码时 Hermes 自动用主力模型回答，不用开两个窗口。

## 启动脚本（macOS）

一键启动 Hermes + Open WebUI：

```bash
#!/bin/bash
# ~/start-hermes.sh

# 检查 Docker
if ! docker ps > /dev/null 2>&1; then
    echo "请先启动 Docker Desktop"
    exit 1
fi

# 启动 Open WebUI
docker start open-webui 2>/dev/null || docker run -d \
    -p 3000:8080 \
    --add-host=host.docker.internal:host-gateway \
    -v open-webui:/app/backend/data \
    --name open-webui \
    ghcr.io/open-webui/open-webui:main

# 启动 Hermes Gateway
hermes gateway run
```

## 生产部署建议

### 安全加固

```yaml
gateway:
  control_ui:
    allow_insecure_auth: false   # 关闭不安全认证
    auth_token: "strong-secret"  # 设置强认证
  
  rate_limit:
    enabled: true
    max_messages_per_minute: 30
    burst: 5
```

### 监控

```yaml
logging:
  level: info
  format: json                  # JSON 格式便于日志系统接入
  audit:
    enabled: true
    log_tool_calls: true
```

### 备份

```bash
# 备份全部数据
tar -czf hermes-backup-$(date +%Y%m%d).tar.gz ~/.hermes/
```

关键备份内容：

| 路径 | 重要性 |
|------|--------|
| `~/.hermes/config.yaml` | ⭐ 核心配置 |
| `~/.hermes/.env` | ⭐ API Key |
| `~/.hermes/state.db` | ⭐ 会话历史 |
| `~/.hermes/memory/` | ⭐ 记忆文件 |
| `~/.hermes/skills/` | ⭐ 自定义技能 |
| `~/.hermes/tools/` | 自定义工具 |
| `~/.hermes/plugins/` | 插件 |

> [!tip] cron 自动备份
> 配置一个[[05-高级特性#定时任务（Cron）|Cron 任务]]每天自动备份 `~/.hermes/`，保留最近 7 天的归档，省心。

## 升级指南

```bash
# 查看当前版本
hermes --version

# 升级到最新
hermes upgrade

# 指定版本
hermes upgrade --version 2026.4.20
```

### 升级注意事项

1. ⚠️ **先备份** `~/.hermes/`
2. 检查 `CHANGELOG` 有没有 Breaking Changes
3. 升级后运行 `hermes config validate`
4. 再跑 `hermes doctor` 确认一切正常

> [!warning] 升级前一定备份
> 升级脚本大概率不会动你的配置和数据，但万一遇到小概率事件——备份在手，天下我有。
