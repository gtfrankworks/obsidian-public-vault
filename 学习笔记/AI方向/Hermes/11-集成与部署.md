# 🔌 集成与部署

## Docker 部署

### 官方 Docker 镜像

```bash
# 拉取
docker pull ghcr.io/nousresearch/hermes-agent:latest

# 运行
docker run -d \
  --name hermes \
  -v ~/.hermes:/home/hermes/.hermes \
  -p 8642:8642 \
  ghcr.io/nousresearch/hermes-agent:latest
```

### docker-compose.yml

```yaml
version: '3.8'
services:
  hermes:
    image: ghcr.io/nousresearch/hermes-agent:latest
    container_name: hermes
    volumes:
      - ~/.hermes:/home/hermes/.hermes
    ports:
      - "8642:8642"
    restart: unless-stopped
    environment:
      - HERMES_LOG_LEVEL=info
```

## API Server（OpenAI 兼容）

将 Hermes 作为 OpenAI 兼容的 API 服务暴露。

### 启用

```bash
echo 'API_SERVER_ENABLED=true' >> ~/.hermes/.env
echo 'API_SERVER_KEY=my-local-key' >> ~/.hermes/.env
hermes gateway run
```

### 验证

```bash
curl http://localhost:8642/v1/health
# → {"status": "ok"}

# OpenAI 兼容接口
curl http://localhost:8642/v1/chat/completions \
  -H "Authorization: Bearer my-local-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [{"role": "user", "content": "你好"}]
  }'
```

### 支持端点

| 端点 | 功能 |
|------|------|
| `GET /v1/health` | 健康检查 |
| `POST /v1/chat/completions` | Chat Completion（兼容） |
| `GET /v1/models` | 模型列表（兼容） |

### 与 Open WebUI 集成

1. 启动 API Server（见上）
2. Open WebUI → 管理员设置 → 外部连接
3. 添加：
   - URL: `http://host.docker.internal:8642/v1`
   - API Key: `my-local-key`

> ⚠️ `host.docker.internal` 是 Docker 内部访问宿主机的 DNS，Open WebUI 容器需要 `--add-host=host.docker.internal:host-gateway` 参数。

## ACP（Agent Communication Protocol）

与其他 ACP 兼容代理通信。

### 作为 ACP 客户端

```python
delegate_task(
    goal="写一个 Python 脚本",
    acp_command="claude",        # 启动 Claude Code
    acp_args=["--acp", "--stdio"]
)
```

支持：Claude Code、OpenCode、Codex（OpenAI）。

### 作为 ACP 服务端

Hermes 可以作为 ACP 服务端被其他工具调用：

```bash
# 其他 ACP 客户端连接
other-agent --acp-connect hermes://localhost:8642
```

## 启动脚本（macOS）

创建一个快捷启动脚本：

```bash
#!/bin/bash
# ~/start-hermes.sh

# 检查 Docker
if ! docker ps > /dev/null 2>&1; then
    echo "请先启动 Docker Desktop"
    exit 1
fi

# 启动 Open WebUI
docker start open-webui 2>/dev/null || docker run -d \
    -p 3000:8080 \
    --add-host=host.docker.internal:host-gateway \
    -v open-webui:/app/backend/data \
    --name open-webui \
    ghcr.io/open-webui/open-webui:main

# 启动 Hermes Gateway
hermes gateway run
```

## 生产部署建议

### 安全加固

```yaml
gateway:
  control_ui:
    allow_insecure_auth: false   # 关闭不安全认证
    auth_token: "strong-secret"  # 设置强认证
  
  rate_limit:
    enabled: true
    max_messages_per_minute: 30
    burst: 5
```

### 监控

```yaml
logging:
  level: info
  format: json                  # JSON 格式便于日志系统
  audit:
    enabled: true
    log_tool_calls: true
```

### 备份

```bash
# 备份全部数据
tar -czf hermes-backup-$(date +%Y%m%d).tar.gz ~/.hermes/
```

关键备份内容：

| 路径 | 重要性 |
|------|--------|
| `~/.hermes/config.yaml` | ⭐ 核心配置 |
| `~/.hermes/.env` | ⭐ API Key |
| `~/.hermes/state.db` | ⭐ 会话历史 |
| `~/.hermes/memory/` | ⭐ 记忆文件 |
| `~/.hermes/skills/` | ⭐ 自定义技能 |
| `~/.hermes/tools/` | 自定义工具 |
| `~/.hermes/plugins/` | 插件 |

## 升级指南

```bash
# 检查版本
hermes --version

# 升级
hermes upgrade

# 升级到指定版本
hermes upgrade --version 2026.4.20
```

### 升级注意事项

1. ⚠️ 升级前备份 `~/.hermes/`
2. 检查 `CHANGELOG` 了解 Breaking Changes
3. 升级后运行 `hermes config validate`
4. 运行 `hermes doctor` 确认一切正常
