## 🎯 核心定位

Hermes Agent 是一个 **本地优先、平台无关的 AI 代理框架**，强调：

| 特性 | 说明 |
|------|------|
| 🏠 **本地优先** | 数据不离开你的机器，配置文件纯文本 |
| 🔌 **平台无关** | 支持 20+ 消息平台、25+ LLM 提供商 |
| 🛠️ **工具驱动** | 终端、文件、浏览器、代码执行、子代理... |
| 🧠 **记忆与技能** | 持久化记忆 + 可复用的工作流技能 |
| ⏰ **定时任务** | 内置 Cron 调度器，支持条件触发 |
| 🏗️ **可扩展** | Plugin 系统、自定义工具、自定义技能 |

## 🚀 一句话入门

```bash
# 安装
curl -fsSL https://hermes-agent.sh | sh

# 初始化配置
hermes init

# 启动对话
hermes chat

# 启动网关（多平台消息接入）
hermes gateway run
```
