## 🎯 核心定位

翻译成人话：Hermes 就是**一个在你自己的机器上跑的 AI 管家**。

| 特质 | 说人话版 |
|------|---------|
| 🏠 **本地优先** | 数据不出门，所有记忆和配置都是你机器上的纯文本文件 |
| 🔌 **哪都能接** | 20+ 聊天平台、25+ 模型提供商，随便换 |
| 🛠️ **什么都能干** | 跑命令、读写文件、逛网页、调子 Agent、定时执行 |
| 🧠 **记性好** | 跨会话记忆 + 可复用的工作流技能，不用每次都教一遍 |
| ⏰ **自己会定时** | 内置 Cron，不用依赖外部调度器 |
| 🏗️ **能自己加功能** | Plugin 系统 + 自定义工具，想加什么加什么 |

## 🚀 一句话入门

```bash
# 装
curl -fsSL https://hermes-agent.sh | sh

# 初始化
hermes init

# 开聊
hermes chat

# 开网关（接消息平台）
hermes gateway run
```

装完先跑 `hermes chat` 试试水，能聊了再折腾消息平台。
