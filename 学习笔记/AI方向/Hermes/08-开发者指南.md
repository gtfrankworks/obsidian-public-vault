# 👨‍💻 开发者指南

这篇适合想给 Hermes 加功能的人——加自定义工具、写技能、开发插件、配 MCP。如果只是日常使用，这篇可以跳过。

> [!tip] 阅读顺序建议
> 新手先从「添加自定义工具」开始，性价比最高——写一个 Python 函数就能当工具用。
> 写复杂了再拆成技能，再大了才考虑插件。

## 架构深入

### Agent Loop 源码结构

如果你好奇 Hermes 内部长什么样：

```
~/.hermes/hermes-agent/
├── hermes_ai/                # 核心 AI 逻辑
│   ├── agent.py              # AIAgent 类，Agent Loop
│   ├── prompt_assembly.py    # Prompt 组装
│   ├── tool_execution.py     # 工具执行
│   └── session_manager.py    # 会话管理
│
├── hermes_tools/             # 工具系统
│   ├── registry.py           # 工具注册中心
│   ├── terminal.py           # 终端工具
│   ├── file_ops.py           # 文件工具
│   ├── web_search.py         # 网络搜索
│   ├── browser.py            # 浏览器自动化
│   └── ...
│
├── hermes_gateway/           # 网关
│   ├── gateway.py            # 主网关
│   ├── router.py             # 消息路由
│   └── platforms/            # 各平台适配器
│       ├── telegram.py
│       ├── discord.py
│       └── ...
│
├── hermes_cli/               # CLI
│   └── main.py               # CLI 入口
│
├── website/                  # 文档网站
│   └── docs/
│
└── config/                   # 配置模板
```

> [!tip] 想改什么先找对应目录
> 比如想改 Telegram 适配器 → `hermes_gateway/platforms/telegram.py`。
> 想改工具注册逻辑 → `hermes_tools/registry.py`。

### Session Storage（会话存储）

```python

## 添加自定义工具

### 快速创建

```python
# ~/.hermes/tools/weather.py
import requests

def get_weather(city: str, units: str = "celsius") -> dict:
    """获取城市天气
    
    Args:
        city: 城市名（中文或英文）
        units: 温度单位 (celsius/fahrenheit)
    
    Returns:
        包含天气信息的字典
    """
    url = f"https://api.weather.com/v1/{city}"
    response = requests.get(url, params={"units": units})
    response.raise_for_status()
    return response.json()
```

### 工具注册

```yaml
tools:
  custom_tools_dir: ~/.hermes/tools/
  custom:
    - name: get_weather
      module: weather
      enabled: true
```

> [!tip] 函数签名自动生成 Schema
> Python 的类型注解 + 文档字符串，Hermes 会帮你转成 OpenAI 兼容的 `function` 定义。不需要额外写 JSON Schema。

## 创建自定义技能

### 手动创建

```bash
hermes skills create my-skill
# 或直接写文件
```

### 通过对话保存

```
用户：刚才那个工作流挺有用的
🤖 我：要保存为技能吗？
用户：好
🤖 → 自动创建 SKILL.md
```

> [!tip] 对话保存最省事
> 跑通了一个复杂流程后直接让我存成技能，不用自己手动写目录结构和 frontmatter。

### 技能模板

```markdown
---
name: my-workflow
description: 我的专用工作流
---

# 我的工作流

## 触发条件
当用户说"帮我做 X"时

## 步骤
1. 第一步：执行 xxx
   ```bash
   hermes status
   ```
2. 第二步：检查 xxx 结果
3. 第三步：...

## 注意事项
- 注意 A 情况
- 避免 B 错误

## 验证
- 确认输出包含 xxx
- 确认无错误信息
```

## Plugin 系统

插件是扩展 Hermes 功能的包——比单个工具大，可以带多个工具 + 技能 + 默认配置。

### 安装插件

```bash
hermes plugin install github-user/hermes-plugin
# 或从本地
hermes plugin install /path/to/plugin
```

### 开发插件

```
my-hermes-plugin/
├── plugin.yaml              # 插件元数据
├── __init__.py              # 插件入口
├── tools/                   # 自定义工具
│   └── my_tool.py
├── skills/                  # 自定义技能
│   └── my-skill/
│       └── SKILL.md
└── config/                  # 默认配置
    └── defaults.yaml
```

`plugin.yaml`:

```yaml
name: my-plugin
version: 1.0.0
description: 我的插件
author: Frank
entry: __init__.py
tools:
  - tools/my_tool.py
skills:
  - skills/my-skill/
```

> [!warning] 插件依赖管理
> 如果你的工具需要第三方 Python 包，确保它们已经装到了 Hermes 的 Python 环境里，或者在插件文档里注明。

## MCP 集成

通过 Model Context Protocol 连接外部 MCP 服务器——相当于让 Hermes 能用上整个 MCP 生态的工具。

### 配置 MCP 服务器

```yaml
mcp:
  servers:
    filesystem:
      command: npx
      args: ["-y", "@modelcontextprotocol/server-filesystem", "/path"]
    
    github:
      command: npx
      args: ["-y", "@modelcontextprotocol/server-github"]
      env:
        GITHUB_TOKEN: "${GITHUB_TOKEN}"
```

> [!tip] MCP 工具自动发现
> 不用额外配置。配置好 `mcp.servers` 后，Hermes 自动连接到 MCP 服务器，把暴露的工具注入到 Agent 的工具列表里。

## 提示词工程

自定义 System Prompt 可以显著提升 Agent 表现：

```yaml
hermes:
  persona: |
    你叫 Friday，是 Frank 的私人 AI 助手。
    
    沟通风格：
    - 用中文回复，偶尔夹带英文术语
    - 技术问题要深入、准确
    - 回答带来源或推理过程
    - 不要过度道歉
    
    核心原则：
    - 优先理解用户意图
    - 发现问题主动提问
    - 复杂任务分解步骤
    - 记得保存重要信息到记忆
```

> [!tip] persona 越具体越好
> 「你是一个有用的助手」太笼统。「你叫 Friday，用中文回答，技术问题要深入，不要过度道歉」——模型拿到这种 Prompt 表现会好很多。
