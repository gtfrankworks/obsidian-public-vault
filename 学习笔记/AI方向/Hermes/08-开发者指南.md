## 添加自定义工具

### 快速创建

```python
# ~/.hermes/tools/weather.py
import requests

def get_weather(city: str, units: str = "celsius") -> dict:
    """获取城市天气
    
    Args:
        city: 城市名（中文或英文）
        units: 温度单位 (celsius/fahrenheit)
    
    Returns:
        包含天气信息的字典
    """
    url = f"https://api.weather.com/v1/{city}"
    response = requests.get(url, params={"units": units})
    response.raise_for_status()
    return response.json()
```

### 工具注册

```yaml
tools:
  custom_tools_dir: ~/.hermes/tools/
  custom:
    - name: get_weather
      module: weather
      enabled: true
```

函数签名自动生成 JSON Schema。返回 dict 会自动注入回 LLM。

## 创建自定义技能

### 手动创建

```bash
hermes skills create my-skill
# 或直接写文件
```

### 通过对话保存

```
用户：刚才那个工作流挺有用的
🤖 我：要保存为技能吗？
用户：好
🤖 → 自动创建 SKILL.md
```

### 技能模板

```markdown
---
name: my-workflow
description: 我的专用工作流
---

# 我的工作流

## 触发条件
当用户说"帮我做 X"时

## 步骤
1. 第一步：执行 xxx
   ```bash
   hermes status
   ```
2. 第二步：检查 xxx 结果
3. 第三步：...

## 注意事项
- 注意 A 情况
- 避免 B 错误

## 验证
- 确认输出包含 xxx
- 确认无错误信息
```

## Plugin 系统

插件是扩展 Hermes 功能的包。

### 安装插件

```bash
hermes plugin install github-user/hermes-plugin
# 或从本地
hermes plugin install /path/to/plugin
```

### 开发插件

```
my-hermes-plugin/
├── plugin.yaml              # 插件元数据
├── __init__.py              # 插件入口
├── tools/                   # 自定义工具
│   └── my_tool.py
├── skills/                  # 自定义技能
│   └── my-skill/
│       └── SKILL.md
└── config/                  # 默认配置
    └── defaults.yaml
```

`plugin.yaml`:

```yaml
name: my-plugin
version: 1.0.0
description: 我的插件
author: Frank
entry: __init__.py
tools:
  - tools/my_tool.py
skills:
  - skills/my-skill/
```

## MCP 集成

通过 Model Context Protocol 连接外部 MCP 服务器。

### 配置 MCP 服务器

```yaml
mcp:
  servers:
    filesystem:
      command: npx
      args: ["-y", "@modelcontextprotocol/server-filesystem", "/path"]
    
    github:
      command: npx
      args: ["-y", "@modelcontextprotocol/server-github"]
      env:
        GITHUB_TOKEN: "${GITHUB_TOKEN}"
```

MCP 服务器暴露的工具会被自动发现并注入。

## 提示词工程

自定义 System Prompt 提升 Agent 表现：

```yaml
hermes:
  persona: |
    你叫 Friday，是 Frank 的私人 AI 助手。
    
    沟通风格：
    - 用中文回复，偶尔夹带英文术语
    - 技术问题要深入、准确
    - 回答带来源或推理过程
    - 不要过度道歉
    
    核心原则：
    - 优先理解用户意图
    - 发现问题主动提问
    - 复杂任务分解步骤
    - 记得保存重要信息到记忆
```
